# 🐝 Bee Detection & Segmentation using YOLO (ONNX Quantized)

This project implements **object detection and instance segmentation** for beehive analysis using YOLO models.  
Training was conducted on **Kaggle**, followed by **ONNX export and quantization** for optimized inference.

The system detects:

- Bees  
- Varroa mites  
- Drone cells  
- Queen cells  
- Queen bee  

---

## 📁 Project Files

- `Bees-detection.ipynb` → YOLO detection training  
- `Bees-segmentation.ipynb` → YOLO segmentation training  
- `best.onnx` → Quantized ONNX model  

---

## 🧠 Training Environment

- Platform: Kaggle  
- Framework: Ultralytics YOLO  
- Hardware: GPU runtime

## 🔍 Detection Model Training

```python
model = YOLO('yolo12s.pt')

model.train(
    data='/kaggle/working/fixed_drone.yaml',
    epochs=50,
    imgsz=920,
    batch=4,
    lr0=0.001,
    cos_lr=True,
    patience=20,
    augment=True,
    scale=0.5,
    mosaic=1.0,
    mixup=0.1,
    project="/kaggle/working",
    name="drone_bee_Varroa_v3",
    close_mosaic=10
)
```
